The repo_ingestor is a sequential job-start agent designed to ingest and initialize software repositories for processing. It accepts a Git URL (or a ZIP file), credentials, and a branch as input. Its primary actions include: 1) cloning the repository using JGit or a native git client, 2) validating the fetched source code, 3) computing baseline metrics such as lines of code and identifying modules and the build tool, 4) storing a complete snapshot of the repository in an object store, and 5) creating a new job record in a database. The agent's final output is a RepoSnapshot JSON object containing the repo_id, commit hash, a list of modules, and the detected build_tool, which serves as the foundational data for subsequent pipeline steps.
