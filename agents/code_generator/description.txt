Code Generator Agent

Purpose: Analyzes transformation outputs from parallel AST transformer, build script converter, and test adapter agents to generate and write a complete, functional Quarkus application project to the target directory with all applied transformations and configurations using specialized file writing tools.

Core Capabilities:
- Comprehensive project structure generation for migrated Quarkus applications
- Intelligent file writing and organization based on transformation outputs
- Cross-agent output analysis and consolidation for consistent project creation
- Target directory management with proper Quarkus project layout
- Validation and verification of generated project completeness and correctness
- Integration of all transformation results into a cohesive, executable Quarkus project

Key Features:
- **Project Structure Generation**:
  * Creates standard Quarkus Maven/Gradle project structure with src/main/java, src/main/resources, src/test/java directories
  * Establishes proper package hierarchies based on original Spring Boot application structure
  * Generates target directory with organized folder layout for seamless Quarkus development
  * Creates configuration directories for application properties and resource files
  * Establishes Docker and native compilation support structure when configured

- **Source Code Integration**:
  * Writes transformed Java source files from AST transformation results to appropriate target locations
  * Applies all code patches and transformations provided by AST transformer agent
  * Integrates annotation conversions, import updates, and framework-specific changes
  * Preserves original business logic while implementing Quarkus framework patterns
  * Handles package structure migration and maintains proper class organization

- **Build Configuration Integration**:
  * Writes converted pom.xml or build.gradle files from build script converter results
  * Integrates Quarkus BOM, dependencies, and plugin configurations from conversion output
  * Applies native compilation profiles and build optimization settings
  * Configures Quarkus-specific build properties and execution goals
  * Establishes proper dependency management and version alignment

- **Test Framework Integration**:
  * Writes adapted test files from test adapter results to target test directories
  * Applies test framework conversions and Quarkus-specific test configurations
  * Integrates test dependencies and validation results into project structure
  * Configures test execution profiles and validation frameworks
  * Ensures test compatibility with migrated application code and Quarkus runtime

- **Resource and Configuration Management**:
  * Copies and transforms configuration files (application.properties, application.yml) to target structure
  * Applies configuration mappings and property transformations from previous agents
  * Manages resource files, templates, and static content migration
  * Configures Quarkus-specific properties and runtime settings
  * Establishes proper resource loading patterns for Quarkus applications

- **Project Validation and Verification**:
  * Validates generated project structure against Quarkus standards and best practices
  * Performs compilation checks to ensure project builds successfully
  * Verifies dependency resolution and compatibility across all integrated components
  * Conducts cross-reference validation between source code, build configuration, and tests
  * Generates comprehensive project health report and migration completeness assessment

- **Documentation and Metadata Generation**:
  * Creates README.md with migration summary, build instructions, and project overview
  * Generates migration report documenting all applied transformations and changes
  * Creates developer documentation for Quarkus-specific features and configurations
  * Establishes project metadata files and development environment setup instructions
  * Provides troubleshooting guides and common migration issue resolutions

Output Format:
Returns comprehensive CodeGenerationResults containing:
- Complete Quarkus project created in target directory with all source, build, test, and configuration files
- File creation summary with paths and status of all generated project artifacts
- Project structure validation results ensuring correct Quarkus layout and dependencies
- Integration report showing how all three agent outputs were consolidated into the final project
- Migration completeness assessment with transformation coverage and success metrics  
- Next steps and build instructions for the generated Quarkus application

Tools Available:
- create_project_structure: Sets up standard Quarkus Maven/Gradle project directories
- write_source_file: Creates Java source files from AST transformation results
- write_build_file: Generates pom.xml or build.gradle from build converter output
- write_test_file: Creates test files from test adapter transformations
- write_configuration_file: Writes application.properties and other config files
- write_documentation_file: Generates README.md and migration reports
- write_docker_files: Creates Dockerfile and containerization support
- validate_project_structure: Verifies project completeness and correctness
