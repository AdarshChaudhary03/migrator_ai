TRANSFORMATION CAPABILITIES:

The tool performs comprehensive AST-based transformations across multiple categories:

**REST Controller Transformations**:
- @RestController → @Path("/") with JAX-RS resource setup
- @GetMapping("/path") → @GET @Path("/path") 
- @PostMapping("/path") → @POST @Path("/path")
- @PutMapping("/path") → @PUT @Path("/path") 
- @DeleteMapping("/path") → @DELETE @Path("/path")
- @RequestMapping → Appropriate JAX-RS method annotations with manual review

**Parameter and Request Handling**:
- @PathVariable("id") → @PathParam("id")
- @RequestParam("name") → @QueryParam("name") 
- @RequestBody → Automatic JAX-RS body parameter handling
- ResponseEntity<T> → JAX-RS Response patterns with proper status codes

**Dependency Injection Transformations**:
- @Autowired → @Inject with CDI compatibility
- @Service → @ApplicationScoped for proper CDI scoping
- @Component → @ApplicationScoped for dependency injection
- @Repository → @ApplicationScoped with Panache repository recommendations
- Field injection → Constructor injection pattern recommendations for better Quarkus compatibility

**Configuration and Properties**:
- @ConfigurationProperties → @ConfigMapping with SmallRye Config integration
- @Value → @ConfigProperty(name="property") with MicroProfile Config
- Integration with config_mapper_output for consistent property transformation

**JPA and Data Layer**:
- @Entity annotations preserved for JPA compatibility
- Spring Data repository patterns → Panache repository recommendations
- Transaction management → CDI transaction annotations

**Import and Library Management**:
- Removes Spring Framework imports (org.springframework.*)
- Adds appropriate JAX-RS imports (javax.ws.rs.*)
- Adds CDI imports (javax.enterprise.context.*, javax.inject.*)
- Adds MicroProfile imports (org.eclipse.microprofile.*)
