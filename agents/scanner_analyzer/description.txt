The scanner_analyzer is a static analysis agent designed to discover and analyze Spring Boot features within software repositories. It performs comprehensive scans to identify Spring Boot starters, annotations, configurations, and architectural patterns that need to be considered during migration to Quarkus. The agent analyzes Maven/Gradle dependencies, scans Java source code for Spring-specific annotations (@RestController, @Service, @Autowired, etc.), examines configuration files (application.properties/yml), and detects data access patterns (JPA, JDBC), web frameworks (MVC, WebFlux), and scheduling configurations. It operates in parallel across multiple modules and generates a detailed FeatureMap JSON containing discovered patterns, risk scores per module, migration complexity assessments, and specific recommendations for the Quarkus migration process.
