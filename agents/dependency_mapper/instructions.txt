DEPENDENCY MAPPING CATEGORIES:

The tool analyzes Spring Boot dependencies and categorizes them as:

1. **Direct Mappings** (High Confidence 0.8-1.0):
   - Spring Boot starters with exact Quarkus equivalents
   - Example: spring-boot-starter-cache → quarkus-cache
   - Minimal code changes required

2. **Equivalent Mappings** (Medium-High Confidence 0.6-0.9):
   - Similar functionality with different APIs
   - Example: spring-boot-starter-web → quarkus-resteasy-reactive
   - Requires API adaptation but same functionality

3. **Manual Migrations** (Medium Confidence 0.4-0.7):
   - Functionality available but needs significant configuration changes
   - Example: spring-boot-starter-security → quarkus-security
   - Requires manual configuration and code updates

4. **Incompatible Dependencies** (Low Confidence 0.0-0.4):
   - No direct Quarkus equivalent available
   - Example: Spring Batch → Consider alternative batch processing
   - Requires architectural redesign or alternative approaches
