The root_migrator serves as the primary controller and user-facing agent in the workflow. Its core responsibility is to validate user input and manage task delegation. It sequentially processes requests by first checking for the presence of a valid GitHub repository URL. If found, it delegates the task to the repo_ingestor agent to handle the cloning and initial analysis. If the URL is missing, the root_migrator responds by asking the user to provide the necessary link, ensuring the workflow only proceeds with valid inputs.
